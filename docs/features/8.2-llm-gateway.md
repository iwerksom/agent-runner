# 8.2 LLM gateway in front of both harnesses

**Phase 8** · **Status: Planned**

## User story

As a **operator** I want **cost, caps and provider keys held by a gateway (LiteLLM)** so that **caps hold across vendors and keys never enter the sandbox**.

## Issues

- [#19](https://github.com/iwerksom/agent-runner/issues/19) LLM gateway (LiteLLM) in front of both harnesses (open)

## Acceptance

- The worker no longer holds `ANTHROPIC_API_KEY`; a run holds a virtual key capped to its budget.
- The ledger reads spend from the gateway, from one price table, not from each harness's own result message.

## Notes

Also resolves 5.1's MLflow undercount if the gateway emits correct spans.
