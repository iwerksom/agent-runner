# 1.4 Approved work orders reach code

**Phase 1** · **Status: Done**

## User story

As a **maintainer of ledtraad** I want **a ledtraad issue to become an accepted work order and, once I approve it, a draft PR** so that **well-scoped work is executed without me writing the plan**.

## Issues

- [#31](https://github.com/iwerksom/agent-runner/issues/31) Bind work-order-scoper to ledtraad, with GitHub issues as tickets (closed)
- [#40](https://github.com/iwerksom/agent-runner/issues/40) Temporary bridge: execute approved work orders with Claude Code until work-queue runs (closed)

## Acceptance

- `work-order-scoper` reads a ledtraad issue and returns an accepted or rejected order.
- `pnpm orders:publish` posts an accepted order as `wo:proposed`; swapping to `wo:approved` lets the bridge skill execute it into a draft PR.
- The bridge measures the order's premise before changing code and parks if the problem is gone.

## Notes

The bridge is temporary: it is replaced by `work-queue` running in 3.1.
