# 7.4 The rest of the chain: triage, scoper, order, queue, executor

**Phase 7** · **Status: Planned**

## User story

As a **maintainer** I want **a reviewed finding to become a work order, then a draft PR** so that **documentation fixes are made without hand-written plans**.

## Issues

- [#24](https://github.com/iwerksom/agent-runner/issues/24) The rest of findings: triage, scoper, order, queue, executor (open)

## Acceptance

- Triage is deterministic: only `document-stale` is auto-promotable, `repo-changed` is a human's ticket, `unclear` is never promoted.
- Findings are batched by document or class: one order per batch.
- A doc-drift-derived order verifies without a test suite: re-run the finding's command.
- The executor leg waits for 3.1 and 4.1.
