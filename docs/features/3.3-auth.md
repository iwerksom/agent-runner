# 3.3 Auth, once someone other than the author uses it

**Phase 3** · **Status: Planned**

## User story

As a **team lead** I want **sign-in through our identity provider with viewer, operator and admin roles** so that **only the right people can trigger or change agents**.

## Issues

- [#25](https://github.com/iwerksom/agent-runner/issues/25) Auth, once someone other than the author uses it (open)

## Acceptance

- Any OIDC provider, optional in solo mode.
- Role floors hold: `read-only` viewer, `external-writes` admin, everything else operator.
- Registering, editing or removing a repo requires admin.
- Every run records who triggered it.
- The guarded-push helper refuses a `mainBookkeeping` push outside the declared globs (also tracked in 4.1).

## Notes

Until this lands the console stays on localhost.
