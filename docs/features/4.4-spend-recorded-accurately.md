# 4.4 Spend is recorded accurately

**Phase 4** · **Status: In progress**

## User story

As a **operator** I want **the ledger to record what every run really cost, including failed ones, and MLflow to agree** so that **budget caps and cost reports can be trusted**.

## Issues

- [#38](https://github.com/iwerksom/agent-runner/issues/38) A failed run's spend is not recorded (closed)
- [#20](https://github.com/iwerksom/agent-runner/issues/20) MLflow undercounts cost and tokens about 3× (open)

## Acceptance

- A run that fails or hits `maxTurns` still records its cost (#38).
- MLflow shows the ledger's cost and tokens: the runner tags the trace, or the gateway (4.2) emits correct spans (#20).
