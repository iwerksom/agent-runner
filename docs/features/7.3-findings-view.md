# 7.3 Findings view: file a reviewed finding as an issue

**Phase 7** · **Status: Done**

## User story

As a **operator** I want **a findings list per repo and a File issue button** so that **a reviewed finding becomes a GitHub issue with its measuring command as the acceptance check**.

## Issues

- [#34](https://github.com/iwerksom/agent-runner/issues/34) Findings view: file a reviewed finding as a ledtraad issue (closed)

## Acceptance

- `/findings` lists open, filed and closed findings per repo.
- File issue creates an issue with the `finding` label on the repo's GitHub remote; filing writes to the tracker, never the repo, and only on the click.
- The finding records the issue number, so no later run offers it again.
- Not yet exercised: a real File issue click on ledtraad.
