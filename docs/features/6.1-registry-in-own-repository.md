# 6.1 The registry lives in its own repository

**Phase 6** · **Status: Planned**

## User story

As a **team lead** I want **agent definitions, prompts and per-repo bindings in a registry repository, reviewed like code** so that **a team keeps its agents when the engine's author moves on**.

## Issues

- [#23](https://github.com/iwerksom/agent-runner/issues/23) Move the registry into its own repository (open)
- [#16](https://github.com/iwerksom/agent-runner/issues/16) Agent.id is global, so one prompt bound to two repos needs two ids (open)

## Acceptance

- A registry repository is loaded at runtime and validated with zod; adding an agent needs no change to the engine.
- The agent key is `(definition, repo)`, so one prompt bound to two repos is one agent with two bindings (#16).
