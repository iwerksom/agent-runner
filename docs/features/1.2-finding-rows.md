# 1.2 Finding rows with a fingerprint

**Phase 1** · **Status: Done**

## User story

As a **operator** I want **findings kept as durable rows, deduplicated across runs and closed when fixed** so that **tomorrow's run adds only what is new**.

## Issues

- [#33](https://github.com/iwerksom/agent-runner/issues/33) Finding rows with a fingerprint: dedupe across runs, close what stops appearing (closed)

## Acceptance

- A `Finding` row carries repo, source run, fingerprint, title, file, verdict and state.
- The fingerprint is agent + file + normalised claim, never the line.
- Two consecutive runs on an unchanged repo do not re-report known findings: each run re-checks the open ones by id.
- A finding closes only when a run re-measures it as `fixed`, never because a run left it out.
